# 超星学习通 · 全自动刷课

`auto-study` 是一个面向超星学习通课程页面的 Tampermonkey 用户脚本，提供视频播放辅助、任务点状态识别、自动进入下一节，以及可选的 AI 章节测验作答功能。

**当前公开发布版本：v1.0**

> 本项目仅供个人学习、页面自动化研究与合法授权场景使用。使用前请确认学校、教师及平台规则，并自行承担使用自动化工具可能产生的成绩、账号及其他风险。脚本不保证 AI 答案正确，也不保证平台页面更新后仍然可用。

## 功能特性

### 视频与播放辅助

- 自定义 `0.25～16` 倍播放速度，默认 `2` 倍。
- 自动静音、暂停后续播、换视频后恢复设置。
- 播放器持续拒绝高倍速时，当前视频自动回退到 `2` 倍。
- 识别已完成的视频任务，避免重复播放并进入后续任务。
- 只读分析播放器已有的状态响应，辅助识别平台完成标记延迟。
- 同页有多个视频或其他未完成任务时，不会仅凭一个视频完成就跳过整节。

### 视频弹题与章节测验

- 识别常见视频弹题，自动选择、提交并处理未完成的弹题。
- 支持常见单选题、多选题和判断题的章节测验识别。
- 可接入 OpenAI 兼容接口完成章节测验作答。
- 高精度模式采用“分析＋复核”，出现分歧时进行第三次裁决；快速模式每题只请求一次。
- 本地解析常见超星字体混淆，尽量还原发给模型的题干和选项。
- 自动处理“还有未做完的题”提示，避免带着空题提交。
- 区分“不及格必须重做”和“公布分数后的可选重做”。
- 支持“未达到及格线，请重做”结果弹窗，确认后清空旧答案并重新作答。
- 章节测验提交后等待平台完成标记；标记延迟时最多自动刷新一次。

### 自动导航与维护

- 视频或测验完成后自动进入下一节。
- 识别常见空白章节，避免流程停住。
- 最后一节完成后停止自动化；末章仍有下一卡片时先尝试切换卡片。
- 换页、刷新后可由 Tampermonkey 自动重新注入。
- 提供页面内设置面板、悬浮状态条、运行日志及诊断命令。
- 单文件发布，正常使用不需要安装 Node.js 依赖或额外下载字体库。

## 安装

### 方式一：Tampermonkey（推荐）

1. 在浏览器中安装并启用 **Tampermonkey（篡改猴）**。
2. 打开本仓库中的 [`auto-study.user.js`](auto-study.user.js)，点击 **Raw**。
3. 浏览器如果弹出 Tampermonkey 安装页，确认并安装。
4. 如果没有自动弹出安装页，在 Tampermonkey 中新建脚本，将文件完整内容粘贴进去并保存。
5. 打开超星学习通课程页面并刷新。看到右下角“刷课脚本已启动”提示，说明脚本已经运行。

更新脚本时，用新版完整替换旧脚本，然后刷新课程页面。

### 方式二：浏览器控制台（调试用）

在课程页面按 `F12`，打开 Console，粘贴完整脚本并运行。此方式刷新后不会保留，AI 请求还可能受浏览器跨域限制，因此日常使用仍推荐 Tampermonkey。

## 快速开始

### 只使用视频功能

1. 打开 Tampermonkey 菜单，找到本脚本。
2. 点击 **“设置倍速 / 自动静音”**。
3. 设置倍速和静音选项，将 **API Key 留空**。
4. 点击 **“保存并刷新”**。

API Key 留空时 AI 答题关闭。章节测验不会盲猜答案，需要人工处理；视频弹题仍可能使用非 AI 的选项尝试流程。

### 开启 AI 章节测验

1. 点击 **“设置 AI Key / 接口 / 模型”**。
2. 填写 API Key、完整接口地址和模型名。
3. 选择答题模式、请求间隔及超时时间。
4. 保存并刷新课程页面。

默认配置如下：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 播放倍速 | `2` | 可设置 `0.25～16`，高倍速取决于播放器支持 |
| 自动静音 | 开启 | 可在设置面板关闭 |
| AI 答题 | 关闭 | 填写 API Key 后开启 |
| 接口地址 | `https://api.deepseek.com/chat/completions` | 填完整的聊天补全接口，不只是域名 |
| 模型名 | `deepseek-chat` | 以账号实际可用模型为准 |
| 答题模式 | 高精度 | 每题通常请求 `2～3` 次，速度更慢、消耗更多 |
| 请求间隔 | `1500 ms` | 被限流时可调大到 `3000 ms` 或更高 |
| 单次请求超时 | `60 秒` | 推理模型可尝试 `60～90 秒` |

(实际建议：使用Qwen-plus以获取简单快速的回答能力）

常见 OpenAI 兼容接口示例：

| 服务 | 接口地址 | 模型示例 |
| --- | --- | --- |
| DeepSeek | `https://api.deepseek.com/chat/completions` | `deepseek-chat`、`deepseek-reasoner` |
| Kimi | `https://api.moonshot.cn/v1/chat/completions` | `moonshot-v1-8k` |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions` | `qwen-plus` |

以上模型名只是配置示例，不代表当前账号一定可用。脚本头的 `@connect` 已声明上述三个服务域名；使用其他兼容服务时，需要按实际情况补充对应域名的 `@connect` 权限。

## 菜单与手动控制

在浏览器工具栏打开 Tampermonkey，即可使用以下菜单：

| 菜单 | 用途 |
| --- | --- |
| 设置 AI Key / 接口 / 模型 | 打开统一设置面板 |
| 设置倍速 / 自动静音 | 打开统一设置面板 |
| 恢复 2 倍速并刷新 | 高倍速播放异常时恢复默认倍速 |
| 运行诊断 | 输出视频、frame、章节测验识别信息 |
| 显示 / 隐藏悬浮状态条 | 切换右下角状态显示 |
| 复制最近日志 | 复制排查问题所需的运行日志 |
| 停止本页自动化 | 停止当前页面的定时自动操作 |

也可以在控制台使用：

| 命令 | 用途 |
| --- | --- |
| `stopAutoStudy()` | 停止当前页面自动化，刷新后可能再次启动 |
| `nextSection()` | 手动尝试进入下一节 |
| `muteAll()` | 静音所有视频并开启自动静音 |
| `unmuteAll()` | 恢复声音并关闭自动静音 |
| `aiOff()` | 临时关闭 AI |
| `aiModels()` | 查询当前 Key 可见的模型列表 |
| `cxProbe()` | 输出播放器及 frame 诊断信息 |
| `pageQuizDebug()` | 输出章节测验识别信息 |
| `copyLog()` | 复制最近运行日志 |

如需刷新后也不再运行，请同时在 Tampermonkey 中禁用本脚本。

## 使用建议与限制

- **优先使用 2 倍速。** 高倍速只修改播放器倍率，不伪造观看时长或进度；播放器可能拒绝高倍速，平台也可能按自身规则记录学习状态。
- **不要仅凭视频播放结束判断任务完成。** 平台完成标记可能延迟，脚本会综合任务状态和可读取的播放器状态，但仍以平台最终记录为准。
- **AI 答案不保证正确。** 高精度模式只能降低部分误判，不能保证满分；重要测验请先人工核对。
- **目前主要支持单选、多选和判断题。** 填空、简答、附件、特殊互动题及自定义考试页面不保证可用。
- **平台页面更新可能导致识别失效。** 跨域 frame、特殊播放器、学校定制页面及验证码等场景可能需要单独适配。
- 建议让课程标签页保持可运行状态，避免浏览器休眠或系统睡眠中断播放。
- 脚本不会主动拖动视频进度条，也不会伪造观看进度。

## 隐私与数据安全

- 设置优先保存在 Tampermonkey 的本地存储中，不可用时回退到页面 `localStorage`。
- API Key 不会写死在公开脚本中；启用 AI 后，Key 会作为认证信息发送给你配置的服务商。
- 启用 AI 后，题干和选项会发送给相应接口，用于生成答案。使用前请确认课程内容及服务商的数据政策。
- 字体还原使用脚本内置的本地字形指纹表，不需要把题目截图发送给额外 OCR 服务。
- 导出的日志包含页面 URL、时间和运行信息，可能间接包含课程信息。提交 Issue 前请删除 API Key、个人信息及其他敏感内容。
- 不要把包含真实 Key 的配置、日志或截图提交到 GitHub。

## 故障排查

### 改成高倍速后无法播放

使用菜单 **“恢复 2 倍速并刷新”**。如果播放器反复重置倍速，脚本会对当前视频回退到 2 倍；仍无法播放时请使用平台默认速度。

### AI 请求失败

- `401 / 403`：检查 Key、额度及接口权限。
- `404` 或模型不存在：核对完整接口地址和模型名，可运行 `aiModels()` 查看可用模型。
- `429` 或触发限流：增大请求间隔，并检查账号 RPM、并发及额度限制。
- 请求超时：将超时时间提高到 `60～90 秒`，同时检查网络和服务商状态。
- 题目仍有大面积异常字符：停止自动提交，复制日志并附上报错时的页面截图进行排查。

### 视频或测验不进入下一节

常见原因包括：平台尚未标记完成、同页还有其他未完成任务、出现未及格重做流程、页面结构未被识别，或者当前已经是最后一节。先查看悬浮日志，再运行诊断菜单。

### 提交 Issue 时建议提供

- 浏览器和 Tampermonkey 版本。
- 脚本版本及复现步骤。
- 已脱敏的运行日志。
- 页面截图或相关 DOM 结构。
- 是否使用 AI、接口类型及答题模式；**不要提供真实 API Key**。

## 开发与回归测试

普通使用者只需安装 `auto-study.user.js`。开发者可以使用 Node.js 运行无第三方依赖的模拟 DOM 回归测试，建议使用 Node.js 18 或更新版本：

```bash
node --check auto-study.user.js
node --check test-auto-study.cjs
node test-auto-study.cjs
```

测试覆盖字体还原、AI 答案解析、视频完成状态、多任务保护、末章停止、必须重做与可选重做、失败弹窗、完成标记延迟、倍速回退等场景。

这些测试用于验证脚本内部逻辑，**不能替代真实课程页面的端到端测试**。
